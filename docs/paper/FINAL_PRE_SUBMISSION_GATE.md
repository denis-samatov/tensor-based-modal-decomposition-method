# Release and submission boundary

This software tree prepares v2.2.0. Publication of a tag, allocation of a version-specific DOI and three transferred-portal checks remain external steps. The corresponding author confirmed authorship, affiliations, CRediT, funding role, interests, data-access wording, AI disclosure and exclusivity; the supplied ORCIDs are recorded in CITATION.cff. The official Declaration Tool export requires author login if the portal requests it. The author supplied the ACG preparation requirements; HTTP 403 alone is not a blocker. The prior v2.1.0 DOI is not this release's identifier. Local editorial audit logs and upload receipts are not distributed here.

## Validation

Use [release notes](RELEASE_NOTES.md) and [paper build instructions](README.md). The exact Git revision is obtained with `git rev-parse HEAD`; an exported archive is accompanied by its external release receipt. Do not move a published tag after adding DOI metadata.
