# Reproducibility guide

## Environment
- **Python version**: 3.10+ recommended
- **Dependency installation**:
  ```bash
  python -m venv .venv
  source .venv/bin/activate
  pip install --upgrade pip
  pip install -e ".[dev]"
  ```
- **OS Assumptions**: The pipeline is developed and tested on Linux/macOS. 

## Data
- **Required Data**: The Brugge field simulation benchmark tensors (pressure and oil saturation).
- **How to obtain**: Please download the dataset from the GitHub repository.
- **Folder structure**: Extract the dataset into the `data/` directory at the root of the repository such that the `.npy` tensor files are present in `data/brugge/`.
- **Exclusions**: Raw simulation outputs are not tracked in the GitHub repository due to file size constraints.

## Quick smoke test
Verify that the package is correctly installed by running the basic decomposition example:
```bash
python examples/basic/01_tucker_decomposition.py
```
This should execute without errors and print the tensor approximation errors.

## Reproduce manuscript results

**Note**: The following commands map the methodological stages described in the manuscript to the exact evaluation scripts.

### 1. Main Grid-Wide and Well-Only Metrics
To run the full TBMD--QR--TBCS evaluation pipeline on the held-out Brugge splits:
```bash
python scripts/evaluation/evaluate_windowed_tbmd_qr_cs_forecasting.py
```
- **Expected input**: Brugge `.npy` files in `data/brugge/`.
- **Expected output**: Aggregated CSV metrics in `results/metrics/` and raw `.npy` reconstructions.
- **Estimated runtime**: ~15-30 minutes depending on hardware.

### 2. Figure 5 and Figure 6

## Troubleshooting
- **Missing Data (`FileNotFoundError`)**: Ensure you have downloaded the data from Zenodo and extracted it to `data/`.
- **Missing Dependencies**: Ensure the virtual environment is activated and you installed via `pip install -e ".[dev]"`.
- **Memory Issues (`OOM` or `Killed`)**: The Brugge tensors are large. Ensure you have at least 16GB of RAM. If OOM persists, reduce the batch size or spatial resolution in the configuration.
- **LaTeX/Matplotlib Issues**: Generating PDF figures might require a local LaTeX installation. If you lack LaTeX, matplotlib will fall back to default fonts, but layout might slightly differ from the published manuscript.
