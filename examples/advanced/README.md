# Modal tensor processing example

`01_modal_tensor_processing.py` demonstrates modal dictionary construction with the current API.
For first use, prefer the four [basic examples](../README.md). Historical notebooks are preserved
in the [paper provenance archive](../../docs/paper/audit/README.md); obsolete legacy/fix demos are removed.
Public `TBMD.modules`/`TBMD.utils` compatibility imports remain available.

```bash
python examples/advanced/01_modal_tensor_processing.py
```
